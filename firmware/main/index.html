Home Wi-Fi

Checking network…

2.4 GHz WPA2 personal network. SSID: 1–32 bytes; password: 8–63 printable ASCII characters. A successful save closes the AP after 60 seconds; move to the home LAN and station IP. Credentials are saved only after an IP address is acquired. Connection failures keep the previous setup; storage failures report whether restoration was verified or persistence is uncertain.

Setup/recovery: join Cleverbox, WPA2 password cleverbox, then open http://192.168.4.1/ manually. After normal startup, hold BOOT/IO9 for at least five seconds, then release: recovery stays open until Finish recovery or a successful Wi-Fi save. EN restarts without erasing setup. Configured boots and router outages never open the AP. Do not hold BOOT during reset: this can enter download mode. BOOT access through the supplied enclosure is unverified; opening it or a verified access hole may be necessary. Failed Wi-Fi trials keep an already open session. Finish recovery closes it after 60 seconds, even offline; BOOT opens it again. Forgetting Wi-Fi preserves radiators, MQTT, timezone, discovery cleanup and admitted commands. Local HTTP has no login; use a trusted network.

Device time

Checking device time…

Default UTC0 (no DST). Sweden: CET-1CEST,M3.5.0/2,M10.5.0/3. DST needs explicit M transition rules. Saving the timezone affects new commands only.
Offline bench: explicitly set UTC time Enter UTC, not local time (2020–2099). This is an explicit manual clock, cleared at reboot. Network synchronization can replace it later.

Commands use device time. If time is unavailable, connect home Wi-Fi for SNTP or set it manually here. Time setup never transmits radiator settings. Admitted commands keep their clock snapshot and advance monotonically through retries.

MQTT broker

Checking MQTT…

Home Assistant discovery (opt-in): observations and diagnostics appear automatically. Draft/Apply controls use the HA package.

Home Assistant setup guide

Local TCP broker; no TLS. Use a trusted LAN and broker topic ACLs. HTTP and NVS are unencrypted. Each configuration save replaces all fields; re-enter the password when saving. Stored passwords are never returned. Disable/enable keeps credentials. Forget preserves radiators, Wi-Fi, time and admitted RF commands. MQTT state is separate from requested settings; commands require the current session and a single-use token or new request ID (see docs/mqtt.md).
