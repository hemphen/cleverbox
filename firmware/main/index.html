Home Wi-Fi

Checking network…

2.4 GHz WPA2 personal network. SSID: 1–32 bytes; password: 8–63 printable ASCII characters. Credentials are saved only after an IP address is acquired. Connection failures keep the previous setup; storage failures report whether restoration was verified or persistence is uncertain.

Setup/recovery: join Cleverbox with the random password printed to serial at boot, then open http://192.168.4.1. The AP stays available while connecting, closes 60 seconds after connection unless persistence is uncertain, and reopens on network loss. Forgetting Wi-Fi preserves all radiator configuration and admitted commands. Local HTTP has no login; use a trusted network.
